# Modelos de site | Darlan Hora

Sites modelo para apresentar a clientes, feitos em HTML e CSS puros, sem dependências.

- `index.html`: página inicial com os modelos
- `personal-trainer/`: modelo para personal trainer
- `nutricionista/`: modelo para nutricionista

Nomes, depoimentos, preços (R$ XXX) e registros profissionais são fictícios ou estão em aberto, para serem trocados pelos dados de cada cliente.

## Publicar no GitHub Pages

Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`. O site fica em `https://darlanhora.github.io/<nome-do-repositorio>/`.

## Trocar as cores

As cores principais estão em variáveis no topo de cada `index.html`:

```css
:root{--accent:#D4FF3A;}
```
